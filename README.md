This package collects the current numerical experiment scripts, their solver
modules, and their required parameter data. Figure numbers below follow the
paper figure filenames, rather than the internal LaTeX label names.

## Setup and running

The main scripts use Python 3.10 or later with NumPy, SciPy, and mpmath.
The memory-measurement scripts for Figures 9, 10, and 12 use Windows process
memory APIs and require Windows in their present implementation.

From this package directory in PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\plot_pfull_accuracy.py
```

Replace the script name with the appropriate script from the table. Run each
script from this directory so subprocesses and local imports resolve correctly.
The main outputs are SVG figures and CSV data under `outputs/`.
The resource plots for Figures 9 and 10 are written under
`outputs/fast_slow_resource_vs_phase/`.

Some plotting routines reuse existing CSV data. A new checkout, with no
`outputs/` directory, recomputes the data. After a solver change, existing CSV
data must also be refreshed. Filenames preserve their historical names:
Figure 4 currently uses arrival rates 0.20 to 0.30, and Figure 6 uses 1.49 to
1.51, despite wider ranges appearing in their filenames.

The main script defaults and related experimental variants have been copied
without modification. Runtime and memory measurements will depend on the
machine, software versions, and execution conditions; running the code does
not guarantee pixel-identical resource plots to a previously recorded run.

## Shared files and data

- `plot_distribution_accuracy.py` is shared by several figure scripts.
- `methods/` contains eight required solver modules, including the embedded
  deterministic/Erlang solver and the Erlang lumping module imported by the
  resource script.
- `CME parameters/CME20.csv` provides the order-20 CME representation.
  Lower CME orders used by the main figures are defined in `methods/cme.py`.
- `data/Bernstein20.csv` and `data/Bernstein50.csv` provide the Bernstein
  representations for Figure 13.
- `precision-experiment/` is a separate historical experiment with its own
  `methods/` namespace and dependencies. Keep it separate from the main code.

## Corrections included in the main experiments

`methods/fast_slow.py` includes auxiliary phase `j=-1` when aggregating the
expanded slower model into physical customer counts. Metrics are computed
from the complete normalized distribution.

For Figure 12, `plot_distribution_accuracy_max_vs_memory.py` performs three
fresh-subprocess measurements per method and uses the median. The memory
quantity is the increase in the Windows OS-reported `PeakWorkingSetSize`
counter relative to the post-import peak counter. The process stays alive
while the parent reads the counter, avoiding the previous 1 ms polling scheme.
These repetitions reduce variability but do not guarantee equal memory
measurements between executions. This revised procedure applies to Figure 12;
the resource script for Figures 9 and 10 retains its existing measurement code.

## Precision experiment status

The separate precision bundle has not been reconciled with the final paper
figures. Its own `methods/dual_bounds_method.py` still omits phase `j=-1` in
the expanded slower aggregation. It also lacks the Erlang 10/D curve shown in
the current Figure 22. See `precision-experiment/README.md` before using that
bundle as a reproduction of Figures 22 and 23.

The package includes source and input parameters only. Generated figures,
recorded measurement CSV files, virtual environments, caches, temporary
builds, and obsolete alternative plotting scripts are not included.
